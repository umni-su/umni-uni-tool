# Руководство по созданию Pull Request (Внесение изменений)

Благодарим вас за желание улучшить проект! Чтобы внести свои изменения через новую ветку и отправить их автору, выполните следующие шаги.

## Пошаговый процесс

### 1. Сделайте Fork репозитория
1. Откройте страницу оригинального репозитория в браузере: `https://github.com/umni-su/umni-uni-tool`.
2. В правом верхнем углу нажмите кнопку **Fork**.
3. GitHub создаст копию этого репозитория в вашем личном аккаунте (например, `https://github.com`).

### 2. Клонируйте ВАШ форк на компьютер
Вам нужно работать со своей копией, а не с оригиналом. Если вы уже выполнили команду `git clone` для оригинального репозитория, перенастройте удаленный адрес (remote) или просто склонируйте свой fork заново в другую папку:

```bash
# Клонируем именно ваш форк
git clone ......

cd umni-uni-tool
```

### 3. Свяжите локальный репозиторий с оригиналом (Upstream)
Чтобы ваши файлы оставались актуальными, добавьте ссылку на оригинальный проект:
```bash
git remote add upstream https://github.com/umni-su/umni-uni-tool.git
```

### 4. Создайте новую тематическую ветку
Никогда не делайте изменения напрямую в ветке `main` или `master`. Создайте новую ветку с понятным названием (например, `feat/add-login`, `fix/bug-123`):

```bash
# Создает новую ветку и сразу переключает на нее
git checkout -b имя-вашей-ветки
```

### 5. Внесите изменения и сделайте коммит
Отредактируйте или добавьте нужные файлы в проект. После этого зафиксируйте изменения:

```bash
# Проверяем, какие файлы изменились
git status

# Добавляем файлы в индекс (Staging)
git add .

# Создаем коммит с понятным описанием на английском или русском языке
git commit -m "feat: добавлена новая функция/исправлена ошибка"
```

### 6. Отправьте ветку в ваш Fork на GitHub
Загрузите созданную ветку с изменениями в свой удаленный репозиторий:

```bash
git push origin имя-вашей-ветки
```

### 7. Создайте Pull Request (PR) автору
1. Перейдите на страницу **вашего форка** на GitHub (`https://github.com`).
2. Сверху появится плашка с предложением отправить изменения. Нажмите кнопку **Compare & pull request**.
3. Убедитесь, что:
    * **base repository** — это оригинальный `umni-su/umni-uni-tool` (ветка `main`/`master`).
    * **head repository** — это ваш форк `ВАШ_НИК/umni-uni-tool` (ваша новая ветка).
4. Напишите понятное название для PR и кратко опишите, что именно вы сделали.
5. Нажмите кнопку **Create pull request**.

---
После этого автор проекта получит уведомление, сможет проверить ваш код, оставить комментарии или принять (замержить) изменения в основной проект.
